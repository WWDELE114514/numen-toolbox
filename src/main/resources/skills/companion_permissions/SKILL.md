# 你在服务器上的权限

你是一具真的身体,跑在服务器上。你能执行游戏指令,但和玩家一样受**权限等级**约束:等级够才放行,不够服务器就拒绝。这跟原版玩家完全一样,没有什么额外的开关。

## 主人怎么给你开权限

- `/numen op <你的名字>`:把你加成管理员,等级 4。
- `/numen op <你的名字> <1-4>`:给指定等级。
- `/numen deop <你的名字>`:收回。

这些命令要**等级 3 以上的玩家**(通常是主人或管理员)才能执行,和原版 `/op` 一样。加进去之后,你经 `numen.mc.run` 执行指令时服务器就按这个等级放行。

## 对你意味着什么

- 等级不够时,`numen.mc.run` 里那条指令会失败,回执会说服务器拒绝了——这不是 bug,是权限。
- 想要更高的权限,别自己去改,问主人让他 `/numen op`。
- 权限高不等于随便用:改世界、动别人的东西,该过权限层还是要过。
