# Numen:Extra

[言出法随(Numen)](https://github.com/Dwinovo/minecraft-numen)的附属模组,给智能体补上几件事:

- **模组感知**:`toolbox.mods.*` —— 看清服务器装了哪些模组。
- **跨模组物品搜索**:`toolbox.items.*` —— 按关键词在任何模组里找到确切物品 id。
- **精妙背包存取**:`toolbox.backpack.*` —— 读写精妙背包里的东西。它的内容按 UUID 存在世界里、不在物品自身,原版的读容器和 `numen.gui.view` 都看不见它,这一组直接向精妙背包要它的存储。
- **卓越前线武器**:`toolbox.sbw.*` —— 列出、查看、开火与换弹、切换弹种(装了 [SuperbWarfare](https://github.com/Mercurows/SuperbWarfare) 时)。
- **卓越前线载具**:`toolbox.vehicles.*` —— 骑在坦克、炮车、导弹车上时:装填炮弹、切换弹种、让炮自己索敌与预判开火。
- **鞘翅飞行**:`toolbox.elytra.*` —— 穿上鞘翅、起飞、滑翔到某点、降落。

另加一条 `/numen op <名字> [等级]` / `/numen deop <名字>` 命令,把智能体的权限接到原版的 op 列表上,让她和玩家一样按权限等级执行指令。

## 依赖

| 模组 | 需要 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.203+ |
| 言出法随(Numen) | 必需 |
| 卓越前线(SuperbWarfare) | 可选 |
| 精妙背包(Sophisticated Backpacks) | 可选 |

没装可选模组时,对应的那一组不会出现,其余功能照常。

## 载具火控是怎么打的

骑上坦克、炮车、导弹车之后，火炮不跟她的视线走——它跟炮塔走。这一组把火控整套管起来，**节奏与准头都不自己另算，全听这门炮自己的数据**：

1. **索敌**：以炮口为心，在炮塔射界和这门炮的射程内挑最近的敌人。制导武器(导弹)用它的锁定射程，能到几百格；视线被挡住的不算，自己人(她、主人、同队、这辆车)一律跳过。
2. **预判**：普通炮弹用卓越前线自己的弹道解算——按弹速、重力、目标速度解出飞行时间、算提前量。坦克炮有重力、弹速才 20，不重力的提前量会全落在脚前。激光与制导武器(导弹)没有飞行时间，直指目标——导弹发射后自己纠偏追。
3. **转炮塔**：直接用卓越前线自己的 `turretAutoAimFromVector`——它按炮塔当前真实朝向算差、每刻走一小步、夹在射界里，和真人转得一样自然。
4. **开火**：能不能打、什么时候能打，全问 `GunData.canShoot()`——弹药、换弹中、拉栓中、过热它都算进去了。坦克主炮 `Magazine:1` 打一发要换 5 秒弹，机枪没弹匣直供背包、按射速连发，各自的节奏都由炮自己的数据决定，模组不设任何"一发隔多久"的常量。

开火的同时把她的视线也拧向炮口指的方向——她不会再看你，除非你在打的目标旁边。

## 已知的本体问题与修补

`numen.use.item` 在言出法随 0.1.4.1 里声明的返回类型写成了 `Clicks.Clicked`,可右键一个会开界面的物品(精妙背包、末影箱、工作台……)时真正交回的是 `GuiOps.Window`,派发器编码时会抛异常并让服务器整刻崩掉。本模组在服务器第一次刻把这个函数的返回编码器换成一个按运行期类型编码的,不改本体的代码就把这一处补齐了。
