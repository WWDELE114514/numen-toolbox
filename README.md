# Numen:Extra

[言出法随(Numen)](https://github.com/Dwinovo/minecraft-numen)的附属模组。装了就多几样本事：

- 她能看清服务器装了哪些模组（`toolbox.mods`），也能跨模组按名字搜到任何一件物品的确切 id（`toolbox.items`）。
- 精妙背包（`toolbox.backpack`）。背包的内容存在世界的一份数据里、不在物品身上，原版那套读容器根本看不见它，这一组直接找精妙背包要它的存储，存取都行。
- 卓越前线的枪（`toolbox.sbw`，装了 [SuperbWarfare](https://github.com/Mercurows/SuperbWarfare) 时）：查、拿、开火、换弹、切换弹种。
- 卓越前线的车（`toolbox.vehicles`）：骑上坦克、炮车、导弹车后，装填炮弹、切换弹种，炮会自己找人、算提前量、拧过去开火。
- 鞘翅（`toolbox.elytra`）：穿上、起飞、滑翔到某点、降落。

另有 `/numen op <名字> [等级]` 和 `/numen deop <名字>`，把她的权限接到原版 op 列表上，跟玩家一样按等级执行命令。

## 依赖

Minecraft 1.21.1、NeoForge 21.1.203+、言出法随（必需）。卓越前线和精妙背包是可选的，没装时对应的那一组就不出现，其余照常。

## 骑在车上怎么开炮

坦克、炮车的火炮不跟她的视线走，跟炮塔走，而炮塔得有人拧。这一组把拧炮塔这件事接了过来。难的地方在于每门炮脾气差得远——坦克主炮打一发就得换五秒弹，机枪没弹匣、从弹药里直接供着按射速连发，导弹打出去自己会追目标。所以这里不给开火定任何"隔几刻一发"的规矩，能不能打、什么时候能打，一律问炮自己的状态：弹药够不够、是不是在换弹、是不是在拉栓、有没有过热，它说能打才打。

炮弹的提前量用卓越前线自己的弹道解算——按弹速、重力和目标速度算出它飞多久、该瞄目标将要到的地方。坦克炮有下坠、弹速也不快，不算这一笔弹会全落在目标脚前。导弹和激光不飞时间，直接指目标就行。

转炮塔这一步直接调卓越前线自己的函数，跟真人转得一样自然，不会自己抽风。开火的同时她的视线也顺着炮口走，所以她看着目标，不会一会儿回头看主人一眼。

## 顺带修掉的一个本体 bug

`numen.use.item` 在言出法随 0.1.4.1 里把返回类型写成了 `Clicks.Clicked`。可对一个会开界面的东西（精妙背包、末影箱、工作台……）右键时，真正交回的其实是 `GuiOps.Window`。派发器拿着 Clicked 的编码器去编码一个 Window，会抛异常，一路冒到服务器整刻，直接把服务器带崩。本模组在服务器第一次刻把这个函数的返回编码器换成一个按运行期类型编码的，不动言出法随本身的代码就补上了。
